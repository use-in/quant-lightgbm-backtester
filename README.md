# LightGBM 기반 시계열 주가 예측 및 퀀트 백테스팅 파이프라인


## 1. 프로젝트 개요
Yahoo Finance API와 LightGBM 머신러닝 알고리즘을 활용하여 주가 변동 방향을 예측하고, 
시계열 검증 구조를 통해 매매 전략의 리스크와 결과를 평가하는 퀀트 백테스팅 파이프라인 프로젝트입니다.


## 2. 사용 기술 스택
* **Language:** Python
* **Data Source:** `yfinance` (Yahoo Finance API)
* **Data Processing & Backtesting:** `Pandas`, `NumPy`
* **Machine Learning & Validation:** `LightGBM`, `Scikit-learn (TimeSeriesSplit)`
* **Visualization:** `Matplotlib`


## 3. 파이프라인 구조
1. **데이터 수집 및 유효성 검증:** `yfinance` API 데이터 수집 및 비어있는 티커에 대한 예외 처리
2. **피처 엔지니어링:** 이동평균선 비율(SMA Ratio), RSI, 일일 변동성 등 기술적 지표 생성
3. **시계열 교차 검증:** 미래 데이터 누수 방지를 위해 `TimeSeriesSplit` 적용
4. **ML 모델 학습 및 신호 생성:** LightGBM 분류 모델을 활용한 내일 주가 상승(1)/하락(0) 예측
5. **백테스팅 및 리스크 평가:** CAGR, MDD, Sharpe Ratio 산출 및 시각화


## 4. 백테스팅 결과 및 비교 분석

### 미국 우량주 (AAPL) vs 국내 대형주 (005930.KS)

| 종목 | 전략 CAGR | 단순 보유 CAGR | 전략 MDD | 샤프 지수 |

| **Apple (AAPL)** | **26.42%** | 36.95% | -30.56% | **1.03** |
| **삼성전자 (005930.KS)** | **-3.10%** | 15.75% | -32.69% | **-0.11** |


## 5. 결과 분석 및 한계점

* **미국 시장과 국내 시장의 성과 격차 원인:**
  * **AAPL (성공):** 꾸준한 우상향 추세와 하락장 방어 메커니즘이 잘 작동하여 샤프 지수 1.03 달성.
  * **삼성전자 (실패):** 단순 기술적 지표만으로는 외국인/기관 수급 및 반도체 업황의 영향을 크게 받는 국내 대형주의 노이즈를 제어하지 못해 엇박자 매매 발생.

* **프로젝트를 통해 얻은 시사점:**
  1. 단일 기술적 지표 기반의 1일 예측 모델은 시장에 따른 과적합 위험이 큼.
  2. Buy & Hold를 넘어서려면 포트폴리오 비중 조절 및 수급/거시경제 피처의 결합이 필수적임.
